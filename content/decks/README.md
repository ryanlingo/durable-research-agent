# Decks

Slide decks for talks, internal reviews, and interview walkthroughs.

## Put here

- `.pptx` / `.key` / Google-export PDFs of finished decks
- Source outlines when the deck is written as markdown first (`*.md` next to the export)

## Naming

```
YYYY-MM-DD-short-slug.pptx
YYYY-MM-DD-short-slug-outline.md
```

Example: `2026-07-31-durable-agents-crash-lab-outline.md`

## Rules

- Temporal terms: [`../concepts/temporal-concepts.md`](../concepts/temporal-concepts.md)
- Messaging: Feature → Benefit → Outcome ([`../concepts/feature-benefit-outcome.md`](../concepts/feature-benefit-outcome.md)
- Diagrams: reuse [`../assets/diagrams/`](../assets/diagrams/); do not redraw a second style system
- Voice: `context/STYLE.md` (local)
