# Content studio: start here

Teaching assets for the durable research lab. Code and UI live at the repo root; this folder is the curriculum.

## Pick a path

| You have… | Start with |
|-----------|------------|
| 5 minutes, no keys | [Tutorial 01: Showcase UI](tutorials/01-showcase-ui.md) |

## Rules of the lab

1. Fair comparison: same tools and parallel search on both stacks.  
2. Intentional non-Temporal resume gaps are curriculum (`concepts/recovery-gaps.md`).  
3. Temporal vocabulary matches `concepts/temporal-concepts.md` and the Temporal glossary.  
4. Feature → Benefit → Outcome for audience-facing copy (`concepts/feature-benefit-outcome.md`).
