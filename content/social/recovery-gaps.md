# LinkedIn

A fair non-Temporal agent is easy to spoil in two directions. Make it a toy and Temporal looks inevitable. Perfect its resume path and you have rebuilt a workflow engine next to the model calls.

This lab keeps retries, stage checkpoints, parallel search, and human approval, and it keeps intentional recovery gaps: mid-write drafts, all-or-nothing gather, coarse status gates, re-eval on some resumes, manual nested hydrate, token totals that lag in-flight bills.

Those gaps are curriculum, not unfinished todos. The token total after a forced crash is still the cheapest proof that "we added SQLite" is not Durable Execution.
